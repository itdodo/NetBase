# NetBase 部署与启动指南

> 本文档覆盖三种场景：**本机开发**、**Docker 单机部署**、**云服务器上线**。
> 所有命令在项目根目录 `E:\02AI\ZCode\Net通用基础框架` 执行（Windows + Git Bash 环境）。

---

## 一、本机开发模式（改代码 + 调试）

> 前提：本机装有 Docker Desktop（数据库跑容器里）、.NET 10 SDK、Node.js 20+

### 1. 启动数据库（只需一次）

```bash
docker compose -p netbase up -d db
```

PG 数据存在 Docker 卷 `netbase-pg-data`，**容器删除数据不丢**。宿主机调试端口 **5544**。

### 2. 启动后端 API（端口 5566）

```bash
cd src/NetBase.Api
dotnet run
```

- 首次启动自动建表 + 种子数据（admin / Net123456）
- Swagger：http://localhost:5566/swagger
- 连接串在 `src/NetBase.Api/appsettings.json`（已对齐 compose 密码）

### 3. 启动前端（端口 5173）

```bash
cd web
npm run dev
```

- 访问 http://localhost:5173，代理 /api → 5566

### 日常重启速查

```bash
# 只重启数据库
docker restart netbase-db

# 改了 C# 代码 → 重新跑后端
cd src/NetBase.Api && dotnet run

# 改了前端代码 → vite 热更新自动生效，无需重启

# ⚠️ 本机 dotnet run 和 Docker api 容器二选一（端口不冲突：5566 vs 8680，可同时跑但数据同库）
```

## 二、Docker 单机部署（日常主用，推荐）

> 前端 + API + PG 全在 Docker，一条命令启动，访问 http://localhost:8680

### 启动 / 重建

```bash
docker compose -p netbase up -d --build
```

- `--build`：改了代码后需要（前端重新构建 + 后端重新发布，约 3-5 分钟）
- 不加 `--build`：仅重启容器（配置变更时用）
- 数据卷：`netbase-pg-data`（数据库）、`netbase-uploads`（上传文件）、`netbase-backup`（备份）——**`down` 不带 `-v` 数据不丢**

### 常用运维命令

```bash
# 看日志
docker logs -f netbase-api
docker logs -f netbase-db

# 重启单个容器
docker restart netbase-api

# 停止（保留数据）
docker compose -p netbase down

# ⚠️ 彻底删除（连数据卷一起删，慎用）
docker compose -p netbase down -v

# 进 PG 命令行
docker exec -it netbase-db psql -U netbase -d netbase
```

### 环境变量（compose 内置，可覆盖）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `NETBASE_API_PORT` | 8680 | UI/API 端口（避开 Windows 保留区间，bind 失败先查 `netsh excludedportrange`） |
| `NETBASE_DB_PORT` | 5544 | PG 宿主调试口 |

## 三、云服务器上线（外网访问）

### 前提

- 一台云服务器（阿里云/腾讯云轻量 2核4G 即可），已装 Docker
- 已完成「ACR 个人版」开通（镜像仓库），或直接在服务器上 build

### 方式 A：从 ACR 拉取（推荐，服务器无需源码）

```bash
# 1. 登录 ACR
docker login crpi-96nxvgqqlihknu1x.cn-hangzhou.personal.cr.aliyuncs.com \
  -u "itdodo@163.com" -p "docker1688"

# 2. 启动 PG
docker run -d --name netbase-db \
  -e POSTGRES_USER=netbase \
  -e POSTGRES_PASSWORD=改我_强密码 \
  -e POSTGRES_DB=netbase \
  -v netbase-pg-data:/var/lib/postgresql/data \
  --restart unless-stopped \
  postgres:17-alpine

# 3. 启动应用（⚠️ 三处"改我"必须替换）
docker run -d --name netbase-api \
  -p 80:8080 \
  --link netbase-db \
  -e ASPNETCORE_ENVIRONMENT=Production \
  -e Db__ConnectionString="Host=netbase-db;Port=5432;Database=netbase;Username=netbase;Password=改我_强密码;Maximum Pool Size=50" \
  -e ConnectionStrings__Hangfire="Host=netbase-db;Port=5432;Database=netbase;Username=netbase;Password=改我_强密码;Maximum Pool Size=10" \
  -e Jwt__SecretKey="改我_至少32位随机字符串" \
  -e Backup__Directory=/app/backup \
  -v netbase-backup:/app/backup \
  -v netbase-uploads:/app/uploads \
  --restart unless-stopped \
  crpi-96nxvgqqlihknu1x.cn-hangzhou.personal.cr.aliyuncs.com/itdodo2026/netbase:latest

# 4. 安全组/防火墙放行 80 端口
```

### 方式 B：服务器上从源码构建（无 ACR 时）

```bash
git clone git@github.com:itdodo/NetBase.git && cd NetBase
docker compose -p netbase up -d --build
```

### 更新版本

```bash
# 本地推新镜像到 ACR
docker build -t crpi-96nxvgqqlihknu1x.cn-hangzhou.personal.cr.aliyuncs.com/itdodo2026/netbase:v新版本号 .
docker push crpi-96nxvgqqlihknu1x.cn-hangzhou.personal.cr.aliyuncs.com/itdodo2026/netbase:v新版本号

# 服务器拉取并重启
docker pull crpi-96nxvgqqlihknu1x.cn-hangzhou.personal.cr.aliyuncs.com/itdodo2026/netbase:v新版本号
docker stop netbase-api && docker rm netbase-api
# 再执行上面第 3 步（tag 换新版本号）
```

### 自动化（CI/CD 已配好）

- 推送 GitHub → CI 自动测试（全绿才通过）
- 打 tag（`git tag v1.x.x && git push origin v1.x.x`）→ CD 自动构建镜像推到 ACR
- 服务器：`docker pull` + 重启即可

## 四、生产必改清单

| 项 | 默认值 | 改为 |
|---|---|---|
| `Jwt__SecretKey` | CHANGE_ME_... | ≥32 位随机字符串 |
| PG 密码 | YourStrong@Password1 | 强密码 |
| admin 密码 | Net123456（首次登录后修改） | 强密码 |
| 验证码 `sys.captcha.enabled` | true（生产建议开启） | 按需 |
| HTTPS | 未配 | 建议加反向代理 + 免费证书 |

## 五、故障排查速查

| 症状 | 排查 |
|---|---|
| API 起不来（bind 失败） | 端口落 Windows 保留区间：`netsh interface ipv4 show excludedportrange protocol=tcp`，换端口 |
| "password authentication failed" | PG 密码不匹配：`docker exec netbase-db psql -U netbase -c "ALTER USER ..."` 或检查连接串 |
| Docker 容器全 Exited(255) | Docker Desktop 崩了：重启 Docker Desktop → `docker start netbase-db netbase-api` |
| 页面 404（API） | 检查控制器路由是否存在（`/api` 前缀），详见质检修复记录 |
| 本机 dotnet run 和 Docker 端口冲突 | 本机 5566 / Docker 8680，二选一跑，数据同库不冲突 |
